# MemeVault Support

## Quick answers

**The keyboard won't paste a meme.**
Settings → General → Keyboard → Keyboards → Memes → turn on **Allow Full Access**. Then tap a meme and tap Paste in the app you're typing in.

**The MemeVault keyboard isn't listed.**
Settings → General → Keyboard → Keyboards → Add New Keyboard → Memes.

**"Save to MemeVault" is missing from the share sheet.**
Scroll to the end of the share sheet's app row and tap More, then turn on MemeVault.

**AI descriptions or semantic search say unavailable.**
These need a device that supports Apple Intelligence and the feature to be switched on in Settings. Text search, tags and everything else still work.

**My memes aren't syncing.**
Check Settings → [your name] → iCloud has iCloud Drive on and MemeVault enabled. In MemeVault, Settings shows "iCloud sync: On" when active. Sync can take a few minutes.

**I deleted a meme by mistake.**
Menu → Recently Deleted. Memes stay there for 30 days.

**How do I back up or move my library?**
Menu → Settings → Backup → Export Library, save the zip, then use Import Backup on the other device.

**Does iCloud sync count as a backup?**
No. Deletions sync too. Use Export Library for an independent copy.
